# WeChat Styler - 让公众号排版回归内容本身

一个让 Markdown 文章优雅呈现在微信公众号的排版工具。

**核心理念：** 克制的高级杂志感，让读者专注内容而非花哨排版。

---

## 为什么需要这个工具？

市面上的公众号排版工具要么：
- 样式过于花哨，喧宾夺主
- 服务不稳定，随时可能失效
- 无法批量处理，效率低下
- 不支持自定义，千篇一律

**WeChat Styler 解决这些问题：**
- ✅ 9 套克制优雅的杂志主题
- ✅ 本地运行，永不失效
- ✅ 支持批量转换
- ✅ 完全可自定义
- ✅ 符合 WCAG 可访问性标准

---

## 快速开始

### 1. 基础用法

```bash
# 使用默认主题（kami 纸感）
/wechat-styler path/to/article.md

# 指定主题
/wechat-styler path/to/article.md --theme magazine-ink
```

转换完成后，打开生成的 HTML 文件，复制全部内容，粘贴到微信公众号编辑器即可。

### 2. 批量转换

```bash
# 转换某个文件夹下的所有文章
/wechat-styler "articles/*.md" --theme kami

# 转换多级目录
/wechat-styler "01_项目/内容创作/**/*.md" --theme magazine-ink
```

### 3. 自定义参数

```bash
# 调整字号和强调色
/wechat-styler article.md --theme kami --font-size 17 --accent-color "#1B365D"

# 指定输出路径
/wechat-styler article.md --output custom-output.html
```

## 常见问题

### Q: 为什么复制到公众号后背景色消失了？

A: 这是微信编辑器的限制。我们已经在所有背景色上做了多层声明，最大程度降低丢失概率。如果仍然丢失，可以尝试：
1. 使用"粘贴并保留格式"
2. 在浏览器中打开 HTML，从浏览器复制

### Q: 图片为什么没有居中？

A: 确保你的图片链接可访问。我们已经在图片上添加了居中样式，但如果图床不可访问，公众号会显示占位符。

### Q: 可以自定义字体吗？

A: 可以。创建自己的主题配置文件（参考 `themes/` 目录下的 YAML 文件），然后使用 `--theme your-theme` 指定。

### Q: 支持哪些 Markdown 语法？

A: 支持标准 Markdown 语法，包括：
- 标题（h1-h6）
- 段落、加粗、斜体、行内代码
- 引用块
- 有序/无序列表
- 代码块
- 表格
- 图片
- 链接

### Q: 代码块会保留语法高亮吗？

A: 不会。为了保证在公众号编辑器中的稳定性，我们使用统一的代码块样式，不做语法高亮。

## 技术说明

### 核心特性

1. **完全内联样式**：所有样式都内联到 HTML 标签中，确保在微信编辑器中不丢失
2. **Solid Hex 背景色**：不使用 `rgba()`，所有背景色都是实色，降低丢失风险
3. **多层背景声明**：在外层、内容层、文本层重复声明背景色
4. **WCAG 可访问性**：所有主题的颜色对比度都符合 WCAG AA 标准（≥ 7:1）
5. **响应式行长**：桌面端每行 25-35 字，移动端自适应

## 设计理念

### 为什么是"克制的高级感"？

公众号排版的终极目标是**让读者专注内容**，而不是被花哨的样式分散注意力。

我们的设计原则：
1. **留白优于装饰**：用空间而非线条分隔内容
2. **层次优于颜色**：用字号和字重而非多种颜色建立层次
3. **温暖优于冷峻**：用暖色调背景降低长时间阅读的疲劳
4. **克制优于丰富**：每个主题只用 1-2 个强调色

### 为什么是"杂志感"？

杂志排版经过上百年的演化，已经形成了成熟的视觉语言：
- 清晰的信息层级
- 舒适的阅读节奏
- 专业的视觉质感

我们把这些经验应用到公众号排版中，让你的文章看起来像一本精心编辑的杂志。
