# Provenance 模板

每个调研报告末尾附带 provenance 清单，记录引用来源和验证状态。

## 模板

```markdown
---

## 来源清单（Provenance）

| # | 来源 | URL | 抓取时间 | 可信度 | 核查状态 |
|---|------|-----|---------|--------|---------|
| [^1] | <作者/机构>, "<标题>" | <URL> | YYYY-MM-DD | 高/中/低 | verified / mismatch / broken |
| [^2] | ... | ... | ... | ... | ... |

### 核查说明

- verified：URL 可访问，引用内容与原文一致
- mismatch：URL 可访问，但引用内容与原文有出入（已在报告中标注）
- broken：URL 无法访问（引用已替换或移除）

### 未覆盖的已知局限

- <如果有重要角度未能覆盖，在此说明>
- <如果存在 FATAL 级别争议未解决，在此说明>
```

## 规则

1. 每条引用必须出现在 provenance 清单中
2. broken 引用标注后必须在正文中移除或替换
3. mismatch 引用在正文中标注 `[待核实]`
4. 核查时间记录到日期级别
